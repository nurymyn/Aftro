# Contributing

Start from `main` and create a short branch such as
`feat/room-alignment` or `fix/catalog-response`. Write commit messages in
English and describe the outcome, for example `feat: add apartment catalog`.

Open a pull request with the reason for the change, how you verified it, and
a screenshot or short clip when the change affects the interface. Link the
related issue when one exists. Use GitHub releases to summarize changes that
are useful to the whole team.

Use sample floor plans and 3D assets that the team has permission to share.
Keep credentials and build output in local configuration.
